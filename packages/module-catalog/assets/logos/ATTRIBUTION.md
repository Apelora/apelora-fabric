# Logo attribution

Brand marks are the SVG paths from the [Simple Icons](https://simpleicons.org) project (version 16.35.0). Simple Icons releases its icons under **CC0 1.0 Universal** (see its `LICENSE.md`) unless its metadata names another licence for a mark; the **Licence** column below records, for each file, what Simple Icons' metadata states (CC0-1.0 when it names none). The brand-colour `fill` attribute was added from the same metadata.

The licence covers the icon artwork as distributed. **The marks themselves remain trademarks of their owners.** They are used here only to identify the corresponding open-source software (nominative use). Their presence does not imply endorsement by, or affiliation with, any vendor, and they must not be used as Apelora branding.

Marks under another licence keep it: the Apache-2.0 and BSD-3-Clause marks keep their notices through this file; the CC-BY and CC-BY-SA marks (Debian, Jenkins, OpenTelemetry, PHP, Rocky Linux) are attributed here to their projects through the Simple Icons sources and stay under their licence (any change to those files must be shared under the same licence); Fedora and Keycloak, whose marks come with custom trademark terms, use generic icons. New modules use a mark only when Simple Icons gives it as CC0-1.0 or a permissive licence such as Apache-2.0; otherwise they use an original `generic-*` icon (for example OpenBao, Forgejo and Harbor, whose marks are CC-BY-SA-4.0 or under custom terms).

**Microsoft Windows section:** no Microsoft artwork (Windows, SQL Server, IIS, Exchange or Active Directory logos) is bundled. Those marks are not freely licensed and are no longer distributed by Simple Icons. The Windows modules use original neutral icons (`generic-window`, `generic-desktop`, `generic-directory`, `generic-database`, `generic-server`, `generic-storage`); only the .NET icon (Simple Icons, CC0 artwork) is a vendor mark. Running Windows software requires a valid Microsoft licence; the catalog ships no Windows image. If you hold the right to use Microsoft's official artwork, add the SVGs here, point the class `iconAssetPath` at them and record the licence in this file.

Original, neutral icons created for this project (Apelora, AGPL-3.0-only): `gateway.svg`, `haproxy.svg` (generic load-balancer symbol; **not** the HAProxy mark), `linux-base.svg`, and the `generic-*.svg` set (box, window, desktop, directory, passkey, server, database, shield, queue, chart, network, cache, storage, message broker, search, router, DNS globe, tunnel, rack, logs, traces, bell, key, certificate, eye, branch, pipeline, layers, mail) offered when designing custom modules and used for products without a freely licensed mark (for example HAProxy, Varnish, NATS, ActiveMQ, Memcached, NFS, FRRouting, BIRD, CoreDNS, Unbound, Loki, Tempo, OpenBao, Forgejo and Harbor).
