# Contributing to Apelora Fabric

Thanks for your interest in Apelora Fabric.

## Current contribution policy

Issues, bug reports, reproducible tests, architecture discussions, and documentation suggestions are welcome.

**Do not submit external code contributions for merging yet.** The maintainers must first establish a contributor licensing process supporting the intended AGPLv3 and separate commercial licensing structure, including how copyrights and patent permissions are handled. A standard Developer Certificate of Origin (DCO) alone does not automatically confer commercial relicensing rights.

Once contributor terms are published and reviewed, this document will be revised to explain how to submit pull requests. The repository's AGPLv3 license continues to apply to original code that is publicly released under it.

Security vulnerabilities should be reported privately according to SECURITY.md.
