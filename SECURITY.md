# Security policy

Apelora Fabric is an early-stage project and has not been independently audited. Do not deploy on production hypervisor hosts until the control plane, host agent, network isolation, authentication, and privilege boundaries have undergone security review.

Please avoid posting exploit details or secrets in public issues. For now, contact the maintainers privately through a security contact or GitHub private vulnerability reporting when enabled; repository maintainers should configure the reporting channel before accepting external users.
